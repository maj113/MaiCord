PyThaiNLP Thai word-list data

The experimental Thai boundary data includes subword strings derived from the
PyThaiNLP project's words_th.txt. No PyThaiNLP library or implementation code is
included in the application.

The upstream corpus license identifies words_th.txt as created by the PyThaiNLP
project and released under Creative Commons Zero 1.0 Universal Public Domain
Dedication (CC0-1.0).
